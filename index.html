The layer goes above the selected layer.

Map size

The map is a rectangle of square cells. Painted cells outside the new bounds are cut off, new cells are empty (height 0); objects, notes and pictures keep their place. Converting to another unit multiplies every coordinate, size and height. The layer files are written again. This cannot be undone.

The new map goes into an empty folder (the folder dialog can make one); the open map is saved first. Folder… opens either map later.

GameWorld Painter

Every layer shows one kind of thing on the map seen from above. Pick a tool in the bar at the top, select a layer in the Layers panel, then paint or place objects on it; the Tool Options panel has the settings of the tool, Properties those of the layer (tabs: Layer, Selection, Objects). Click the eye to hide a layer, Alt+click to show only it (Alt+click again to bring the others back). The eye buttons above the list show / hide every layer (hiding keeps the map render; Alt+click hides it too). Visibility, opacity and locks are kept in this browser. The project is a folder (metadata.json and one file per layer): with Autosave on, every change is written there a moment later. The tool checks the folder every second and loads what other programs changed (merged with your unsaved changes); while edit.lock is in the folder it does not write.
